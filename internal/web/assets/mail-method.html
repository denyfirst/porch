The mail check.

What a domain publishes about its mail, and how its delivery is protected.

What is read

Through the resolver: SPF and everything it includes, DMARC, MX, MTA-STS, TLS-RPT, DANE for each mail server, and DKIM keys.

A DKIM key lives at <selector>._domainkey, and DNS cannot list what is under a name, so only the selectors you name, plus the ones common providers document, are read. Your selector is the s= tag in the DKIM-Signature header of any mail you sent. Up to sixteen.

Two connections: the MTA-STS policy file, if the domain announces one, and each mail server (up to eight) on port 25, asked only whether it offers STARTTLS. No message is sent. {{if .Demo}}This deployment makes both, for the one mail domain it checks, which is this project’s own, at most once every fifteen minutes.{{else}}This installation makes them for domains it has been shown control of, or where only its operator can use it. A copy that answers strangers without proof makes neither.{{end}}

The relay question

A mail server inside the domain, such as mail.example.com, is also asked whether it would relay mail for a domain it does not serve. The question uses an empty sender, a recipient under .invalid that cannot exist (RFC 2606), and a reset before any message. A mail server run by a provider is never asked.

How to read a report

  • Findings are graded only where a standard calls something an error: two SPF records, more than ten SPF lookups, +all, two DMARC records, an unusable MTA-STS policy.
  • Observed is not graded: ~all, p=none, and the choice of MTA-STS, DANE, both or neither.
  • Not established is what this check could not settle. It never means nothing was published.

When a mail server does not answer

Many mail servers refuse a connection from an address with no reverse DNS name, which is common on home and VPN connections. The report then says the offer was not established, not that it was refused. On your own copy, give the server a reverse DNS name and pass it with -helo. If your network blocks outbound port 25, the report says so.
