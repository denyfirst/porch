What was sent to your server

Every request carries the user agent {{.UserAgent}}, from every installation of Porch, so a line in your log leads here. Nothing below probes for a weakness.

  • GET / over HTTPS and over HTTP, following up to five redirects that your server names. A redirect to another scheme, or to a host this installation may not reach, is not followed. {{if .Demo}}On this deployment that means the hosts this project owns.{{else}}On this installation that means the domains it has been shown control of.{{end}}
  • GET /.well-known/security.txt, the file RFC 9116 defines.
  • GET / on the other form of the name, with or without www.. Its answer is not followed.
  • One TLS handshake to the site’s IPv6 address, if it publishes one. No request is sent over it.

Nothing else: no guessed paths, no other names, ports 80 and 443 only, and no private, loopback, link-local or reserved addresses.

{{if .Demo}}

This deployment reads the page, and only its own: once, up to one megabyte. An installation somebody runs may read the page of a domain it has been shown control of.

{{else}}

This installation reads the page of a domain it has been shown control of, or one only its operator asked for: once, up to one megabyte. A copy that answers strangers without proof reads no page. The public deployment at denyfirst.dev reads only its own pages.

{{end}}

From a page, only two things are kept: whether it declares a content policy, and the host names of anything it loads over HTTP or from another site. Only the headers this check grades are kept. Cookies are kept by name and attributes, never by value.

To have your domain excluded, see stopping a scan.

How to read a report

  • Findings are graded. Each names a rule and the standard behind it. The worst finding sets the verdict.
  • Observed facts are not graded, because no standard sets a line, such as the length of an HSTS max-age.
  • Not established is what this scan could not settle.
  • A host that answered nothing is ungraded, not weak.
  • The graded HSTS policy is the one from the last HTTPS hop, the one a browser keeps.
