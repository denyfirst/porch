02 / How we work

Three rules.

Every tool we make keeps them, and you can check each one.

  1. 01

    Evidence first.

    A result shows what was seen and the standard behind it. Never a verdict without a source.

    How you check it Our code is public, and every rule in it names the standard it applies.

  2. 02

    Your data stays with you.

    Our tools run on your machine. We collect nothing.

    How you check it Open your browser’s network panel: these pages load nothing from anyone else.

  3. 03

    A clear scope.

    We read only what is already shown. No exploits, no guessing, no logins.

    How you check it Every tool we make publishes each connection it opens. Porch’s list.

03 / Releases

No one of us can ship alone.

Two parties make every release, and neither can do it without the other. Then a third checks both. The last line is yours.

Every release

  1. Done: Tag signedMaintainer git tag -s
  2. Done: Built in publicA workflow build-release.yml, which cannot sign
  3. Done: Rebuilt, every byte matched, signedMaintainer release.ps1 -Compare, SHA256SUMS.sig
  4. Done: Rebuilt again, after publishingAnother workflow reproduce.yml
  5. Yours to do: Checked by youYou Your turn: verify a release
