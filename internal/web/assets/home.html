02 / How we work

Three rules.

Every tool we make keeps them, and you can check each one.

  1. 01

    Evidence first.

    A result shows what was seen and the standard behind it. Never a verdict without a source.

    How you check it Our code is public, and every rule in it names the standard it applies.

  2. 02

    Your data stays with you.

    Our tools run on your machine. We collect nothing.

    How you check it Open your browser’s network panel: these pages load nothing from anyone else.

  3. 03

    A clear scope.

    We read only what is already shown. No exploits, no guessing, no logins.

    How you check it Every tool we make publishes each connection it opens. Porch’s list.
