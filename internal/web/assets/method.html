How to read a report

  • Findings are graded. Each names a rule and the standard behind it. One insecure option makes the whole configuration insecure, because an attacker picks what to negotiate.
  • Observed facts are not graded, because no standard sets a line: a post-quantum key exchange, a verified staple, how many names one key covers.
  • Not established is what this scan could not settle, for example a server that stopped answering.
  • Strong needs a complete scan. If a list was cut short, the verdict is ungraded and the command line exits 4.

Obsolete suites

Go’s TLS library cannot offer obsolete suites, so each family is offered in a hello this program writes itself. Refused means the server accepted none of them; accepted names the suite it chose.

Export-grade
40- and 56-bit keys from 1990s export rules. Breakable today (FREAK, Logjam).
NULL, no encryption
The server is authenticated, but nothing is encrypted.
Finite-field DHE
Classic Diffie-Hellman instead of elliptic curves. RFC 10015 prohibits these in TLS 1.2.
Anonymous, no certificate
No certificate, so anyone on the path can pose as the server.
Downgrade signal
A hello with TLS_FALLBACK_SCSV (RFC 7507). Honoured means the server refused to be pushed to an older version. Reported, not graded.

SSL 3.0 is asked for the same way and shown in the version table.
