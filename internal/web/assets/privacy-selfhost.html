What is kept

{{if .Guarded}}No log of requests. Nothing writes down who asked for a check. What was checked, and when, is kept only in the encrypted history under Results.{{else if .Keeps}}No record of requests. Nothing writes down who asked, or at what time. Which name was checked, and on which date, is kept in the results directory.{{else}}No record of requests. Nothing writes down which name was checked, by whom, or when.{{end}} The service logs only that it started, that it stopped, and a failure to keep a result, never the name.

Your address is held in memory for the rate limit and dropped about three minutes after your last request.{{if .Guarded}} An address that tries to sign in is held the same way, to limit password guesses, and dropped within six minutes of its last attempt.{{end}}

Names checked are held as a short keyed hash for a few minutes, so one server is not scanned in bulk. A host is refused after at least {{.Threshold}} scans in a short window.

Counts of scans and refusals are kept in memory, saved to a file only if one was given, and served at /api/v1/stats. They point at no name and no person.

Results: {{if .Guarded}}every report, encrypted under a key the password seals, so it can be opened or deleted under History. A report is kept as it was drawn: the name checked, what was measured, and the time it was measured. The newest thousand are kept.{{else if .Keeps}}kept on this machine, because it was started with a results directory: per name and check, the date, the verdict and the rules raised. No time of day and nothing about who asked. They are never served over HTTP.{{else}}not kept. Close the page and the report is gone, unless you saved its JSON.{{end}}

{{if or .Guarded .Keeps}}

What this page cannot speak for: file timestamps, backups, and any proxy or container log in front of this machine.

{{end}} {{if .Verified}}

A verification secret is kept in a file only its owner can read. Every proof record is derived from it. Proof is checked again on every scan, so deleting the record ends it.{{if .Guarded}} The domains you add under Domains are kept, sealed like the history.{{end}}

{{end}}

What a scan does

{{if .Verified}}Only names whose domain publishes this installation's record at _porch-challenge.<domain> are checked.{{else}}This installation checks any public name it is given. Without proof, it listens only on this machine's loopback address.{{end}} Private, loopback and reserved addresses are always refused.

  • Transport: TLS handshakes at each version, each closed when it ends. No application data is sent.
  • Reach: GET / over HTTPS and HTTP, following a few redirects; /.well-known/security.txt (RFC 9116); GET / of the www. form of the name; and one TLS handshake to the site's IPv6 address, if it has one. {{if .Whole}}The contacts it names and its expiry date are shown to you. The final page is read once, up to one megabyte.{{else}}A count of security.txt contacts and one date are kept, never an address. No page body is read.{{end}}
  • Mail: DNS lookups for SPF, DMARC, TLS-RPT, MTA-STS, the mail servers, DANE and DKIM keys. {{if .Whole}}It also fetches the MTA-STS policy and asks each mail exchanger on port 25 whether it offers STARTTLS. A mail server inside the domain is also asked whether it would relay for a domain it does not serve, using an address that cannot exist, and reset before any message. No message is ever composed. The mailboxes DMARC reports are sent to are shown to you, and so are the SPF, DMARC and TLS-RPT records as the zone publishes them.{{else}}No mail server is contacted, and DMARC report addresses are shown by domain only.{{end}} If a mail address is typed, the part before the @ is dropped.
  • DNS: lookups for the domain's addresses, name servers, SOA and DNSSEC chain. {{if .Whole}}Each of the zone's own name servers is also asked directly whether it answers for the zone and whether it allows a zone transfer, which is stopped before any record is read.{{else}}No name server is asked directly.{{end}}

No logins, no guessed paths, no exploits, no malformed packets. Each host has its own scan budget, whoever asks.

Who else is asked

  • The DNS resolver this machine uses sees every name checked.
  • The certificate authority of a certificate is asked for its revocation list. One list covers thousands of certificates, so it does not learn which one.
    • {{if .Verified}}
  • The domain's own name servers are asked for its proof record, reached from the root. The root and top-level servers learn only the domain, and all of them see this machine's address.
  • The host itself may be asked for /.well-known/porch-challenge when its domain publishes no record.
  • crt.sh is asked which certificates exist for each name the TLS check reads. It learns that somebody is looking at that name. Only for proven domains.
    • {{end}} {{if .Monitor}}
  • A certificate transparency monitor ({{.Monitor}}) is asked which names under a domain appear in public certificates. Only for proven domains.
    • {{end}} {{if .Register}}
  • A passive register ({{.Register}}) is asked what it has seen under a domain, on this installation's own account. Only for proven domains.
    • {{end}} {{if .ReadsCertificates}}
  • Each name that answers may be asked for the certificate it presents: one handshake, closed when the certificate is read. Only for proven domains.
    • {{end}} {{if .AsksResponder}}
  • The authority's responder is asked whether a certificate has been revoked, because this installation was started with -ask-responder. Only for proven domains.
    • {{end}} {{if .WalksRanges}}
  • Nothing, for an address range you name. Its reverse records are read through the resolver, and not one packet is sent to the addresses themselves. Ranges are read only for whoever runs this installation.
    • {{end}} {{if .AsksNobodyElse}}
  • No certificate transparency log, no passive register and no revocation responder is asked by this service.
    • {{end}}

Stopping a scan

This copy is run by whoever runs this machine, not by the makers of {{.Tool}}. To stop scans from it, contact whoever is responsible for the address they came from.

What is not promised

A report describes one moment and is not an audit or a certification. The software is provided without warranty, under the AGPL-3.0.

Your browser

{{if .Guarded}}One cookie, set when you sign in: a random session token that no script can read, sent to no other site. It ends when you sign out, after twelve hours, or when the installation restarts.{{else}}No cookies.{{end}} No analytics, and nothing loaded from elsewhere. Your browser stores only your colour scheme, if you chose one. The clipboard is written in one place: the Copy button next to a DNS record to publish. A report is never put there.
