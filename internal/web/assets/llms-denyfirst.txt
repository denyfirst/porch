# denyfirst

> denyfirst is an independent team that makes security and privacy tools you can read, rebuild and check for yourself.

- This site sets no cookie, loads nothing from another server, and carries no tracker.
- All code is public under AGPL-3.0. Releases are signed, and can be rebuilt byte for byte.
- No accounts, no telemetry, nothing to sign up for.
